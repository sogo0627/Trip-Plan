安く食べる

ワールドポーターズ5Fのサイゼリヤは500〜1,000円。日曜は混むので、中華街の夕食は17:00ごろに入ると並びにくい。

  1. 横浜駅の東口へ出て、徒歩約3分でスカイビルへ。
  2. ワールドポーターズへは、JR桜木町駅から徒歩約10分（目安）。
  3. 赤レンガ倉庫へはワールドポーターズから徒歩約10分。

江の島の名物

丸焼きたこせんべい（あさひ本店）、サザエのつぼ焼き、女夫婦饅頭。昼は海風が強く、夕方は冷えるので上着を。

夜に温まるなら

ホテル近く（石川町駅から徒歩3分）の銭湯「恵びす温泉」。料金は約500〜600円が目安（要確認）。
経路と運賃（片道約800円）
  1. 石川町（関内）駅から、JRで横浜駅へ。
  2. 横浜駅でJR東海道線に乗り換え、藤沢駅へ（約20分・440円）。
  3. 藤沢駅で小田急江ノ島線に乗り換え、片瀬江ノ島駅へ（約7分・167円）。
  4. 水族館は駅から徒歩約3分。帰りは逆の順路です。

  • B案 上野アメ横で夕食と買い物 → 東京駅へ（予算を抑えやすい）
  • C案 銀座で夕食 → 東京駅 丸の内口の駅舎の夜景
経路（候補・前日に乗換案内で確認）

  2. 大門駅から都営大江戸線で勝どき駅へ。魚がしまで徒歩約13分。
  3. 勝どき駅から大江戸線で豊洲駅へ。ゆりかもめで市場前駅へ。
  4. 市場前駅からゆりかもめで新橋駅へ。銀座線で浅草駅へ。
  5. 浅草から銀座線で上野駅へ。JRで東京駅へ。

日本での注意

  • 電車の中では通話せず、静かに過ごす。
  • エスカレーターは左側に立つ（右を空ける）。
  • 食べ歩きは決められた場所で。ゴミは持ち帰る。
  • チップは不要。
  • 温泉・銭湯は入れ墨があると断られることがある。
  • 温泉施設では有料でタオルを借りられる（数百円程度）。
  • 緊急時：警察110、消防・救急119。
